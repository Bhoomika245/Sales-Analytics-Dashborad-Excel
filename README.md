# Sales Analytics Dashboard (Microsoft Excel)
## Project Overview
This project is an interactive Sales Analytics Dashboard developed using Microsoft Excel. It helps analyze sales performance, customer behavior, product performance, and payment methods through interactive visualizations.
## Tech Stack
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
## Features
- Interactive KPI Cards
- Sales Analysis
- Product-wise Sales Analysis
- Customer Type Analysis
- Payment Method Analysis
- Branch & City-wise Analysis
- Interactive Filters using Slicers
## Dataset
- Supermarket Sales Dataset
